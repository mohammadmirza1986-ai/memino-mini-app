# میمینو — Telegram Mini App

این نسخه فقط برای تست اولیه Mini App است.

## فایل‌ها
- index.html: صفحه اصلی
- style.css: ظاهر صفحه
- app.js: اتصال اولیه به Telegram WebApp API

## بعد از این
1. فایل‌ها را روی یک سرویس HTTPS قرار می‌دهیم.
2. آدرس آن را به @MeminoGameBot در BotFather وصل می‌کنیم.
3. داخل تلگرام تست می‌کنیم.
4. سپس حساب کاربری، دیتابیس، بک‌اند و هسته بازی را اضافه می‌کنیم.

## امنیت
Bot Token را داخل این فایل‌ها یا کد عمومی قرار نده.
